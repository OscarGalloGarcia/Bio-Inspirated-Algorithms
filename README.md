# Bio-Inspired Algorithms

Study repository for the **Bio-Inspired Algorithms** course — Master of Science in Artificial Intelligence (MSC Robotics & AI).

> This repository contains code for academic purposes only: implementations, experiments, and course assignments.

## Course Topics

### Evolutionary Algorithms
- Genetic Algorithms (GA)
- Genetic Programming (GP)
- Evolution Strategies (ES)
- Differential Evolution (DE)

### Swarm Intelligence
- Ant Colony Optimization (ACO)
- Particle Swarm Optimization (PSO)
- Artificial Bee Colony (ABC)
- Firefly Algorithm

### Physics and Chemistry Inspired Algorithms
- Simulated Annealing
- Gravitational Search Algorithm (GSA)

### Artificial Immune Systems
- Clonal Selection (CLONALG)
- Immune Networks

### Biologically Inspired Neural Networks
- Self-Organizing Maps (SOM)
- Hodgkin-Huxley Neuron Models

### Artificial Life and Complex Systems
- Cellular Automata
- Flocking / Boids
